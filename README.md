💻 Portfólio Pessoal

👨‍💻 Sobre o Projeto

Este projeto consiste no desenvolvimento de um portfólio pessoal, criado com o objetivo de apresentar minhas informações, habilidades e projetos desenvolvidos durante meus estudos em Desenvolvimento de Sistemas.

O site possui um layout organizado e personalizado, facilitando a navegação e a visualização dos conteúdos.

🛠️ Tecnologias Utilizadas

- 🌐 HTML5
- 🎨 CSS3
- 📱 Bootstrap
- ⚙️ JavaScript

📂 Seções do Portfólio

- 👤 Perfil: apresentação pessoal e informações sobre mim.
- 💼 Projetos: apresentação dos projetos desenvolvidos por meio de um carousel.
- 📧 Contato: espaço com informações para contato.

✨ Recurso Novo Adicionado

Foi adicionada uma animação aos cards da seção de projetos, proporcionando uma apresentação mais dinâmica e interativa.

⚙️ Como o Recurso Foi Implementado

A animação foi desenvolvida utilizando CSS, por meio das propriedades "transition" e "transform", que permitem criar efeitos de movimento suaves nos cards durante a interação do usuário.

🚀 Funcionamento do Projeto

O site funciona diretamente pelo navegador. O HTML organiza os conteúdos, o CSS personaliza o visual e o Bootstrap auxilia na construção de um layout responsivo.

O menu permite navegar entre as seções, enquanto o carousel possibilita visualizar os projetos apresentados.
